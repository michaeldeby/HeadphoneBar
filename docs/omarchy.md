# HeadphoneBar for Omarchy — coming soon

The Omarchy/Linux edition is planned. There is no Linux installer or working
Linux application in this repository yet. The current app uses macOS Bluetooth,
Core Audio, AppKit and SwiftUI APIs and cannot run on Omarchy.

The planned edition will use Linux Bluetooth/audio interfaces and integrate with
Omarchy's desktop. Hardware compatibility and feature parity will be documented
when an implementation is available. No release date is promised.
