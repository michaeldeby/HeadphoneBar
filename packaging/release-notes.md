## macOS preview

Native menu bar controls for supported Sennheiser, Sony and Bose headphones,
with Sennheiser BTD 700 output switching and advanced USB audio settings.

- macOS 14 or later; universal Apple Silicon / Intel build.
- `.pkg`: installs HeadphoneBar in `/Applications`.
- `.zip`: app bundle for manual installation and Homebrew.
- `SHA256SUMS.txt`: artifact checksums.
- Ad-hoc signed, not Apple-notarized. macOS may block the download; use System
  Settings → Privacy & Security → Open Anyway only if you trust this release.
- Sony/Bose and Intel hardware validation remain incomplete. See README for
  model-specific support and limitations.
